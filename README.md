米米大王运筹学复习网站最终干净版：含云同步、今日全打卡、定位、导出、打印、一键清空。Render 需要环境变量 SUPABASE_URL 和 SUPABASE_SERVICE_ROLE_KEY。

## B站网课功能

本版已接入 B 站视频：
https://www.bilibili.com/video/BV1Uw411f7WM/

功能：
- 每个学习日显示对应网课
- 点击“去B站观看”会跳转到对应分P
- 点击“我已看完”会自动完成该课
- 如果打开视频后页面累计计时达到该课 90% 左右，会自动标记该课完成
- 当当天所有网课完成，会自动勾选当天第一个视频相关打卡项

说明：B 站外部播放进度无法被本站百分百读取，所以自动打卡基于“打开视频后的计时”实现；最稳的方式仍然是看完后点击“我已看完”。


## B站分P修正

该 B 站合集第 1 个分P是导学案/导学篇，不计入正式第1课。
因此本版已修正为：

- 网站第1课 → B站 P2
- 网站第2课 → B站 P3
- ...
- 网站第18课 → B站 P19



## 本版新增：B站真实时长自动读取

- 部署到 Render 后，后端会通过 B站接口读取分P真实时长
- 网站第1课对应 B站P2，因为P1是导学案/导学篇
- 网站第18课对应 B站P19
- 前端网课卡片会显示真实时长，例如 `42分18秒`
- 自动计时打卡也会优先使用真实时长
- 如果本地直接打开 HTML，没有后端接口，会显示“正在获取真实时长”
